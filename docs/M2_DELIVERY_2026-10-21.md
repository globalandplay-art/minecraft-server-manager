## Usable behavior

- Servers registration can load an eligible existing instance immediately and
  switch the current selection without restarting the Manager or old instances.
- Start/stop/restart use existing local UI/API, OperationService and supervisor.
  Selection and registration do not implicitly start Minecraft.
- Multiple distinct-port instances can run simultaneously; same-Manager game/
  RCON port collisions fail `INSTANCE_PORT_CONFLICT` before spawning a child.
- Actual connected game and RCON tuple/PID checks bind readiness, authentication
  and commands to the correct managed launch generation. Unknown ownership fails
  closed. Port/config drift cannot redirect a pending command to another server.
- Restart affects only the target. Same-key replay returns the original operation
  without another launch, including after loading the durable store in a new
  Manager process. Uncertain operations are not automatically resent.
- Original local Origin/authentication/confirmation/recovery gates remain. The
  feature does not enable RCON on ordinary registrations, rewrite ports, accept
  EULA, download a server, modify firewall/network settings or resume P7.
