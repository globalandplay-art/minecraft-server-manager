## Implemented behavior

- Existing Servers registration accepts the shim JAR filename through the same
  trusted Java profile, preview, persistence and hot activation path. There is
  no second registration or process-supervision system.
- Only exact `net.minecraftforge.bootstrap.shim.Main` with a complete binding
  can receive lifecycle capability. Legacy `ForgeBootstrap` detection remains
  read-only. NeoForge does not inherit Forge trust.
- The binding verifies embedded `bootstrap-shim.properties`: exact server
  target and main class, Java requirement >=21. It verifies each SHA-256 and
  Maven coordinate/path in the embedded dependency list, exact same-version
  Forge server/universal pair and actual server `version.json`/Java requirement.
- Manifest Class-Path must reference the bound list only; nested Class-Path,
  duplicate/ambiguous paths, external paths, hardlinks, symlinks/junctions,
  changed files/directories and Multi-Release outer shims are rejected.
  Limits: 256 dependencies, 64 MiB/file, 512 MiB total. Files and directory
  identities are checked again before returning the binding.
- Existing INDEX.LIST files are handled conservatively: only local basename
  references to bound files or confirmed missing targets are accepted. Missing
  targets are checked again and included in binding identity. This is not a
  general JAR Index implementation. Java <21 is not supported by this shim path.
- Registration identity adds private `forgeExecutionSha256`. Preview/save
  naturally bind it; start/restart recollect detection and identity before spawn.
  Changed/missing dependency fails before runtime start; no automatic repair.
- Launch uses the existing fixed Java/Xms/Xmx profile, fixed
  `-Djava.net.preferIPv6Addresses=system`, `-jar <shim>` and `nogui` parameters.
  It does not execute run.bat, user_jvm_args.txt, installer, arbitrary shell
  arguments or downloads. Existing EULA/ownership/port/operation gates remain.
- Forge-specific add-on/world/configuration editing rules are not opened by
  this lifecycle change. M3 and P7 remain out of this checkpoint.
